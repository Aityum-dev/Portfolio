À propos

Bonjour ! Je suis Aityum, étudiant en deuxième année de BUT Informatique à l'IUT2 de Grenoble. Ma passion pour le développement web m'a conduit à créer plusieurs projets personnels, notamment un site immersif pour mon serveur de jeu de rôle "Arzmania".

Je suis passionné par le développement web et la programmation, avec une expérience pratique dans plusieurs langages et technologies. J'ai effectué un stage chez ACS INFORMATIQUE où j'ai travaillé sur le dépannage informatique et la configuration de serveurs.

Au-delà de l'informatique, je suis très investi dans la communauté de jeu de rôle, où je gère un serveur medieval-fantasy. Je combine mes compétences techniques et ma créativité pour créer des expériences immersives et engageantes.

Description

Proxyzen est un projet de semestre ambitieux développé en équipe de 6 étudiants. Il s'agit d'une plateforme destinée aux aidants familiaux de personnes âgées dépendantes, visant à faciliter leur quotidien et à améliorer la qualité des soins.

Mon rôle

  • Développeur frontend principal
  • Analyse des besoins utilisateurs
  • Création de wireframes et maquettes
  • Coordination avec l'équipe backend

Fonctionnalités principales

  • Tableau de bord personnalisé pour les aidants
  • Gestion des rendez-vous médicaux
  • Suivi des traitements et médicaments
  • Partage d'informations avec les professionnels
  • Ressources et conseils pour les aidants

Technologies utilisées

  • Frameworks frontend modernes
  • Design responsive mobile-first
  • Outils de wireframing (Figma, Balsamiq)
  • Méthodologies Agile / Scrum

Arzmania - Site de Roleplay

×

Description

Arzmania est un projet personnel ambitieux : un site web complet pour mon serveur Discord de jeu de rôle médiéval-fantasy. Le site offre une expérience immersive avec des effets visuels sophistiqués, des pages de personnages richement détaillées, et une carte interactive du monde avec des régions cliquables.

Fonctionnalités principales

  • Carte interactive du monde avec régions cliquables
  • Pages de personnages avec design thématique unique
  • Système de portails thématiques avec effets visuels
  • Animations et transitions fluides
  • Design responsive adapté à tous les écrans
  • Intégration avec Discord pour la communauté

Technologies utilisées

  • HTML5 pour la structure sémantique
  • CSS3 avancé avec animations et gradients
  • JavaScript pour l'interactivité
  • Design patterns pour une architecture maintenable

LAN-CARE - Vidéosurveillance

×

Description

LAN-CARE est un projet académique réalisé durant mon BTS CIEL. Il s'agit d'un système complet de vidéosurveillance en temps réel accessible via une interface web. Le projet combine programmation réseau, streaming vidéo et développement web.

Fonctionnalités principales

  • Streaming vidéo en direct depuis les caméras
  • Interface web intuitive pour la visualisation
  • Gestion multi-caméras
  • Système d'authentification sécurisé
  • Architecture réseau optimisée

Technologies utilisées

  • PHP pour le backend et la logique serveur
  • Protocoles de streaming vidéo
  • Configuration réseau avancée
  • HTML/CSS/JavaScript pour l'interface
