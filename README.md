# Portfolio - Aityum

Interactive portfolio website showcasing my projects, skills, and experience as a computer science student. Built with HTML, CSS, and JavaScript featuring interactive modals, responsive design, and modern UI effects.

## 🚀 Features

- **Responsive Design**: Fully responsive layout that works on all devices
- **Interactive Project Modals**: Click on project cards to see detailed information
- **Smooth Animations**: Fade-in effects and smooth scrolling
- **Modern UI**: Gradient effects, hover animations, and clean design
- **Icon Integration**: Font Awesome and Devicon for professional icons

## 🛠️ Technologies

- HTML5
- CSS3 (Grid, Flexbox, Animations)
- Vanilla JavaScript
- Font Awesome
- Devicon

## 📁 Structure

```
Portfolio/
├── index.html      # Main HTML file
├── style.css       # Styles and animations
├── script.js       # Interactive functionality
└── README.md       # Documentation
```

## 🎨 Sections

1. **Hero** - Introduction and call-to-action
2. **About** - Personal presentation and statistics
3. **Skills** - Technical skills categorized with icons
4. **Projects** - Portfolio projects with detailed modals
5. **Education** - Academic timeline
6. **Interests** - Personal interests and hobbies
7. **Contact** - Contact information and links
